# Upload: a spinner instead of the "Uploading…" text

## Summary

While a file uploads, the composer shows "Uploading…" next to the upload
button, set low (the composer aligns to the bottom). Show a spinner in
the upload button instead; screen readers still hear "Uploading…".

## Acceptance Criteria

- Spinner in the upload button while uploading; no text in the composer.
- A status for screen readers; a slower turn with reduced motion.
- Manual check in the browser.
