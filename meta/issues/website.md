# Website

## Summary

A website for Kallisti in site/ (static HTML/CSS, a little JS): the vibe
of Discord's website (dark, big bold headlines, round buttons, sections
with screenshots), Kallisti's teal. Real screenshots with demo content.
Download buttons for the latest GitHub release (asked from the GitHub
API, the releases page without JS), the system's download first. Shown
to the user before anything is pushed or published.
