# Mention pills

## Summary

Like Discord: every @mention of a known user (online or a member) is a
pill for everyone (blue; mine yellow, as before), and a click opens that
user's menu. @everyone/@here pills when the server flagged them. Unknown
names stay text. The whole message stays highlighted for the mentioned
user.

## Acceptance Criteria

- Tests for the highlighting (known, mine, unknown, names with spaces and
  symbols, longest name first).
- Manual check: pills and the menu on click.
