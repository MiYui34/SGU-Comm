# Anti-spam

## Summary

Kallisti has rate limits (requests, logins, guest accounts, connections,
uploads) and moderation tools (time-out, kick, ban, delete, block), but
nothing for a server with open guest access under a spam wave. Sub-issues,
in order of use:

1. guests-read-only.md
2. mass-delete.md
3. slow-mode.md
4. new-account-limits.md
5. word-link-filter.md
6. registration-captcha.md

## Acceptance Criteria

- The sub-issues are done or deliberately dropped.
