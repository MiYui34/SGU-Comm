# Guest accounts and user ids

## Summary

Web guests get real, temporary accounts (cookie, no password) with a Mumble
user id, so everything a user does can be keyed by id, not by name.

## Sub-issues

- Sidecar: the Mumble user id in the identity
- Temporary guest accounts
- Reactions by user id
- Messages and read marks by user id

## Notes

- Only with the built-in server: Kallisti cannot remove registrations on an
  external Murmur. There, guests stay classic guests.
- Temporary accounts have the same rights as other registered users.
