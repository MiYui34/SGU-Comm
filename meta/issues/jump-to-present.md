# Jump to the newest messages

## Summary

Bug report: after scrolling back in the history there is no way back to
the newest message except scrolling. As in Discord, a bar over the message
box: "You are viewing older messages" (or "N new messages" when some
arrived meanwhile) with "Jump to present".

## Acceptance Criteria

- Unit tests for when the bar shows and for the count.
- Manual check: scroll up, bar shows; click, at the bottom; new messages
  while up are counted.
