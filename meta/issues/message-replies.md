# Replies

## Summary

Reply to a message: the reply shows a short quote of it.

## Requirements

- Reply action; the reply stores the message it answers; the quote links
  to it (scrolls there when loaded).
- Replying mentions the author (ping), as in Discord.
- Mumble clients get "> author: quote" before the text.

## Acceptance Criteria

- Store, sidecar and web tests.
