# Idle, do not disturb, custom status

## Summary

Status in the user panel: Online, Idle (also automatic after some time
without activity), Do not disturb (no notifications, no sounds), plus a
custom status (emoji and text, with an end time). Others see the status
dot and the text in the member list and the user menu.

## Acceptance Criteria

- Server: kept per user (registered: stored), sent to all; tests.
- Client: setting, display, DND stops notifications.
